## Was du tun musst

1. **Öffne einmal die neue URL** in deinem Browser:
   👉 **https://123ichbinmitdabei.github.io/terp-sessions/**

2. **Installiere die PWA neu** (im Browser-Menü → „Zum Startbildschirm hinzufügen" / „App installieren"). Die alte Installation auf der Mariana-URL kannst du danach vom Startbildschirm entfernen.

3. **Logge dich mit deinem bestehenden Pseudonym + PIN ein** — das funktioniert unverändert weiter. Das Backend (Datenbank) ist exakt dasselbe Supabase-Projekt; **nur das Hosting der App-Datei selbst ist umgezogen.** Deine Beiträge, Bewertungen, Geräte-Verknüpfungen — alles bleibt erhalten.

4. **Bei Browser-Cache-Problemen:** im Browser → Entwicklertools → Anwendung → Speicher → „Website-Daten löschen" für die alte URL. Dann neu laden.

## Was *nicht* mehr funktioniert

- **Die alte URL** (`marianacannabis.github.io/volcano`) zeigt ab heute eine Hinweis-Seite mit Verweis auf den neuen Standort. Sie bleibt mindestens **30 Tage online**. Danach wird sie ggf. ganz abgeschaltet.
- **Notifications / PWA-Sync der alten Installation** werden nicht mehr aktualisiert. Falls deine PWA-Installation auf der alten URL läuft, bekommst du keine neuen Versionen mehr.
